O projeto

O ReserveTech é um sistema de gestão de reservas de salas e equipamentos, desenvolvido como Projeto Integrador durante o curso de Análise e Desenvolvimento de Sistemas.

A primeira versão do projeto foi construída em Microsoft Access. Com a evolução do trabalho, a equipe decidiu reconstruir a solução como uma aplicação web completa, com backend próprio e banco de dados na nuvem — o que resultou no sistema que está no ar hoje.
